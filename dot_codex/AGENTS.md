# AGENTS.md

## 言語

応答、Markdown ドキュメント、コードコメント、ユーザー向け文言は日本語で書いてください。既存ファイルの言語や外部仕様に合わせる必要がある場合はそちらを優先してください。

## 進め方

- 不明点は、合理的に判断できるなら仮定を明示して進めてください。
- 環境構築、追加インストール、外部サービスの利用など当初の範囲を超える作業は、目的・影響・想定所要時間を示して確認してから行ってください。
- 作業が想定より長引いたら、完了済みの内容・残作業・長引いた原因を整理し、続けるべきか見直してください。

## コードコメント

コメントには、何をしているか（what）ではなく、なぜそうするか（why）を書いてください。

## コミット

コミットメッセージは日本語で書いてください。Conventional Commits などの規約があれば接頭辞や形式は維持し、要約と本文を日本語にします。規約で英語が必須の場合のみ英語にしてください。

## 報告

ファイルは絶対パスで示してください。

## computer-use

`computer-use` 関連ツールは、ユーザーの明示的な許可があるまで呼び出さないでください。

## GitHub CLI 認証

macOS Keychain を使う環境でサンドボックス内の `gh auth status` が失敗した場合は、ホスト環境で同じコマンドを読み取り専用で再実行して判定してください。ホストで成功すれば既存の認証で続行し、失敗すれば再認証を案内してください。

## Worktree

- 通常は今の checkout で作業してください。ブランチ切り替えや作業開始に確認は不要です。
- 追加の worktree を作成・選択・利用する前は、対象パスと理由を示して確認してください。ツールが自動で選んだ場合や、サブエージェントに渡す場合も同じです。確認が取れるまでは読み取り専用のコマンドだけを実行してください。
- 明示されない限り、`git worktree add` などで worktree を手動作成しないでください。
